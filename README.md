## Reflection

The easiest part was adding the three quiz scores and finding the average. The most difficult aspect was ensuring that the original strings did not get mixed in with the converted numbers and that they were both displayed clearly. I found out that the Date object starts counting months at month 0, so I have to add 1 to it. I also found out that Number() can return NaN, and Number.isNaN() and Number.isInteger() test various aspects of the result. I was able to see the results and realize that JavaScript can modify HTML elements rather than just print to the console.
